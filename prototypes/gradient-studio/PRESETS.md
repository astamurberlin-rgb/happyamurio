# Студия градиентов · формат пресетов

Пресеты лежат в `prototypes/gradient-studio/presets.js`:

```js
window.HappyGradientPresets={
  version:1,
  themes:{
    'happy-ref-mint-v1':[ {…пресет 1…}, {…пресет 2…}, {…пресет 3…} ],
    'original':[ … ],          // исходный фон приложений (Day голубой, Meal бордо, Sport фиолетовый)
    …
  }
};
```

## Пресет

Каждое поле можно опустить — тогда берётся исходный вид приложения (`ORIGINAL` в `studio.js`).

```js
{
  name:'Короткое имя',              // видно на карточке, 1–2 слова
  note:'Одна фраза — идея пресета',
  energy:{                          // кольцо энергии Meal, Sport, Day (одно на все приложения)
    eat:  {c0:'#00FFFF',cm:'#7C5AFF',c1:'#FDA6FF',mw:30,s0:59,s1:77,a0:57,a1:75},   // дуга «съедено»
    spent:{c0:'#FDA6FF',cm:'#7C5AFF',c1:'#00FFFF',mw:30,s0:17,s1:45,a0:64,a1:89},   // дуга «потрачено» (лежит сверху в «Баланс»)
    track:20                        // дорожка кольца: белый, % плотности
  },
  apps:{ meal:{ energy:{…как energy…} } },   // необязательно: свои дуги только для Meal
  bars:{                            // полоски строк справа от кольца (КБЖУ / расход / баланс)
    hues:{pink:350,violet:305,blue:262,teal:180},   // тон строки, градусы OKLCH
    chroma:.12,                     // насыщенность OKLCH (0…0,3)
    from:.86, to:.72, over:.56,     // светлота OKLCH: начало полоски, конец, конец за целью (≥ 120 %)
    dot:.80,                        // светлота точки у подписи
    track:22,                       // дорожка полоски: белый, % плотности
    rows:{ pink:{dot:'#…',from:'#…',to:'#…',over:'#…'} }   // необязательно: точные цвета строки вместо формулы
  },
  day:{                             // дуги Day на главном («Сейчас»)
    flow:{mode:'flow',colors:['#55DFD6','#67ADFF','#73FFFF'],intensity:62,softness:76,duration:16},  // поток под дорожкой «Самочувствие»
    balance:{posColor:'#30F7F1',negColor:'#FFB4C4',blend:55,fade:35,alpha:100},                       // баланс: хорошее по часовой, тяжёлое против
    progress:['#FD93FD','#BC61FE','#46FDFC','#7CE3C9']                                                // заливка колец Осознанность, Дневник, Активность (0 / 30 / 62 / 100 %)
  }
}
```

### Что значат числа дуги энергии

- `c0`, `cm`, `c1` — цвета начала, середины и конца. Переход — в OKLCH, коротким путём по кругу оттенков.
- `s0`, `s1` — где на круге (в % полного круга) начинается и кончается переход; до `s0` — цвет `c0`, после `s1` — `c1`.
- `mw` — ширина полосы, где держится цвет середины, % перехода.
- `a0`, `a1` — плотность дуги в начале и в конце, %.
- Дуга «съедено» лежит снизу, «потрачено» — сверху; в «Баланс» видны обе.

### Строки (порядок и тон)

| Вид | розовая `pink` | фиолетовая `violet` | синяя `blue` | бирюзовая `teal` |
| --- | --- | --- | --- | --- |
| Съедено | Белки | Жиры | Углеводы | Клетчатка |
| Потрачено | Тренировки | Покой | Шаги | Время |
| Баланс | Белка до цели | Ходьба | Шаги до цели | Сжечь / Запас |

### Дуги Day

- `flow.mode`: `flow` (цветовой поток), `shimmer` (блик), `wave` (двойная волна), `breathe` (дыхание), `still` (без движения).
- `flow.intensity` — яркость 0–100; `softness` — мягкость перехода 0–100; `duration` — один цикл, 4–40 с.
- `balance.blend` — перелив наверху 0–100; `fade` — растворение концов 0–100; `alpha` — плотность 0–100.
- `progress` — четыре цвета по диагонали кольца со свечением.

## Правила

- Белый текст поверх заливки остаётся читаемым; на светлых темах (Мята, Лагуна) заливка не должна сливаться с фоном.
- На ночных темах — приглушённые, не кислотные цвета; дорожка не ярче 20–25 %.
- Цвета берутся из темы (её фон, свечение, кнопка), а не случайные.
- Три пресета одной темы — заметно разные идеи (например: «в тон фону», «контраст», «мягкий / пастель»).
- Исходный вид приложений не меняется: пресеты — только варианты для сравнения в студии.
