# Студия градиентов · формат пресетов

Пресеты лежат в `prototypes/gradient-studio/presets.js`:

```js
window.HappyGradientPresets={
  version:1,
  themes:{
    'happy-ref-mint-v1':[ {…пресет 1…}, {…пресет 2…}, {…пресет 3…} ],
    'original':[ … ],          // исходный фон приложений (Day голубой, Meal бордо, Sport фиолетовый)
    …
  }
};
```

## Пресет

Каждое поле можно опустить — тогда берётся исходный вид приложения (`ORIGINAL` в `studio.js`).

```js
{
  name:'Короткое имя',              // видно на карточке, 1–2 слова
  note:'Одна фраза — идея пресета',
  energy:{                          // кольцо энергии Meal, Sport, Day (одно на все приложения)
    eat:  {c0:'#00FFFF',cm:'#7C5AFF',c1:'#FDA6FF',mw:30,s0:59,s1:77,a0:57,a1:75},   // дуга «съедено»
    spent:{c0:'#FDA6FF',cm:'#7C5AFF',c1:'#00FFFF',mw:30,s0:17,s1:45,a0:64,a1:89},   // дуга «потрачено» (лежит сверху в «Баланс»)
    track:20                        // дорожка кольца: белый, % плотности
  },
  apps:{ meal:{ energy:{…как energy…} } },   // необязательно: свои дуги только для Meal
  join:{kind:'cap',len:28,from:15,via:[],shadow:38,size:7.5},   // необязательно (1.2): стык дуг в «Баланс», см. ниже
  bars:{                            // полоски строк справа от кольца (КБЖУ / расход / баланс)
    hues:{pink:350,violet:305,blue:262,teal:180},   // тон строки, градусы OKLCH
    chroma:.12,                     // насыщенность OKLCH (0…0,3)
    from:.86, to:.72, over:.56,     // светлота OKLCH: начало полоски, конец, конец за целью (≥ 120 %)
    dot:.80,                        // светлота точки у подписи
    track:22,                       // дорожка полоски: белый, % плотности
    rows:{ pink:{dot:'#…',from:'#…',to:'#…',over:'#…'} }   // необязательно: точные цвета строки вместо формулы
  },
  day:{                             // дуги Day на главном («Сейчас»)
    flow:{mode:'flow',colors:['#55DFD6','#67ADFF','#73FFFF'],intensity:62,softness:76,duration:16,  // поток под дорожкой «Самочувствие»
          light:'none',lightColor:'#E2D6FF',lightDuration:22,glow:50,span:55,halo:26,…},              // необязательно (1.2): оживление, поля HappyArc
    balance:{posColor:'#30F7F1',negColor:'#FFB4C4',blend:55,fade:35,alpha:100},                       // баланс: хорошее по часовой, тяжёлое против
    progress:['#FD93FD','#BC61FE','#46FDFC','#7CE3C9']                                                // заливка колец Осознанность, Дневник, Активность (0 / 30 / 62 / 100 %)
  }
}
```

### Что значат числа дуги энергии

- `c0`, `cm`, `c1` — цвета начала, середины и конца. Переход — в OKLCH, коротким путём по кругу оттенков.
- `s0`, `s1` — где на круге (в % полного круга) начинается и кончается переход; до `s0` — цвет `c0`, после `s1` — `c1`.
- `mw` — ширина полосы, где держится цвет середины, % перехода.
- `a0`, `a1` — плотность дуги в начале и в конце, %.
- Дуга «съедено» лежит снизу, «потрачено» — сверху; в «Баланс» видны обе.

### Строки (порядок и тон)

| Вид | розовая `pink` | фиолетовая `violet` | синяя `blue` | бирюзовая `teal` |
| --- | --- | --- | --- | --- |
| Съедено | Белки | Жиры | Углеводы | Клетчатка |
| Потрачено | Тренировки | Покой | Шаги | Время |
| Баланс | Белка до цели | Ходьба | Шаги до цели | Сжечь / Запас |

### Стык дуг в «Баланс» (1.2)

Виден, когда потрачено меньше, чем съедено: верхняя дуга «потрачено» кончается поверх нижней.

- `kind`: `cap` — круглый конец, как сейчас в приложениях; `fade` — тает; `morph` — перетекает в цвет нижней дуги, потом тает; `shadow` — круглый конец с мягкой тенью.
- `len` — длина перехода, градусы (6–120); `from` — с какого места перехода начинает таять (`morph`, %); `via` — путь цвета для `morph`, например `['#7C5AFF']`.
- `shadow`, `size` — сила и размер тени (`shadow`).

### Дуги Day

- `flow.mode`: `flow` (цветовой поток), `shimmer` (блик), `wave` (двойная волна), `breathe` (дыхание), `still` (без движения).
- `flow.light` (1.2, вкладка «Оживление»): `none`, `stream` (течение), `pendulum` (маятник), `comet` (комета), `aurora` (сияние), `bloom` (раскрытие), `inhale` (вдох). Остальные поля света — как в `HappyArc.DEFAULT` (day-60/arc-motion.js).
- `flow.intensity` — яркость 0–100; `softness` — мягкость перехода 0–100; `duration` — один цикл, 4–40 с.
- `balance.blend` — перелив наверху 0–100; `fade` — растворение концов 0–100; `alpha` — плотность 0–100.
- `progress` — четыре цвета по диагонали кольца со свечением.

## Что лежит сейчас (студия 1.1)

У каждой темы три пресета, место в списке = идея (у трёх ночных тем есть ещё четвёртый, «Рассвет» — о нём ниже; студия 1.2 показывает все пресеты темы):

1. **В тон** — соседние оттенки самого фона, светлее или глубже его.
2. **Контраст** — противоположная сторона цветового круга (тёплое на холодном фоне и наоборот).
3. **Мягкий** — почти белая (на ночных темах серебристая) заливка с лёгким отливом.

| Тема | В тон | Контраст | Мягкий |
| --- | --- | --- | --- |
| Оригинал | Пастель | Солнце | Жемчуг |
| Мята | Глубина | Коралл | Жемчуг |
| Бордо | Пион | Мята и золото | Пудра |
| Фиолетовый бриз | Розовый бриз | Лайм | Жемчуг |
| Золотой закат | Закат | Синий час | Перламутр |
| Орхидея | Лепесток | Лист | Жемчуг |
| Аметист | Кристалл | Цитрин | Лунный камень |
| Лагуна | Отмель | Риф | Жемчуг |
| Спокойный синий | Морозное утро | Янтарь | Туман |
| Ночная бухта | Тихая вода | Костёр | Лунный свет |
| Полуночный ирис | Ирис | Шалфей | Пепел розы |
| Неоновая ночь | Сумерки | Тихий неон | Серебро |

Как они собраны (чтобы новые пресеты были в том же ключе):

- В пресете три опорных цвета. Дуга «съедено» идёт 1 → 2 → 3, «потрачено» — зеркально, как в исходном виде. Те же цвета — в заливке колец Day, в балансе самочувствия и в тонах полосок.
- У «Оригинала» пресет «Пастель» держит отдельные дуги для Meal (`apps.meal`), как исходный вид.
- На обычных темах плотность дуги выше исходной (`a0` 66–86, `a1` 86–98): пастельные цвета без этого теряются на фоне.
- На ночных темах насыщенность ниже (OKLCH до 0,13), дорожка 15–16 %, поток Day медленнее (22–24 с) или «дыхание».
- Поток Day в контрастных пресетах почти белый: цвет, противоположный фону, под полупрозрачной дорожкой даёт серый.
- На светлой «Мяте» пресет «в тон» — тёмный (глубже фона): светлые оттенки бирюзы с фоном сливаются.

### Четвёртый пресет ночных тем — «Рассвет» (по референсу)

У «Ночной бухты», «Полуночного ириса» и «Неоновой ночи» в списке четыре пресета. Четвёртый — «Рассвет», одинаковый во всех трёх темах. Его попросил Астамур 22.11.2026: палитра ночного экрана приложения Sleep Cycle.

- С экрана сняты цвета линии: бирюза `#5DABB5`, середина почти без цвета `#9CA290`, песок `#AFA383`, персик `#CF9D78`. Светлота у всех одна (OKLCH 0,70–0,73).
- В пресете те же тона на ступень светлее, потому что дуга полупрозрачная: бирюза `#7DCDD9` → светлая середина `#E3DDD1` → персик `#E8B184`.
- Середина почти без цвета (насыщенность ниже 0,03), поэтому переход идёт «цвет → свет → цвет», без зелёного посередине.
- Переход на кольце энергии растянут почти на весь круг (`s0` 20, `s1` 86; у «потрачено» 14 и 80). У остальных пресетов он стоит как в приложении (59 → 77 %). Так палитра читается как плавный ход от холодного к тёплому.
- Полоски: персик, песок, аква, бирюза (тоны 58, 82, 192, 210). Дуги Day: поток из тех же трёх цветов, хорошее — бирюза, тяжёлое — персик.
- Правило «цвета берутся из темы» здесь нарушено намеренно: это пресет по референсу.


## Правила

- Белый текст поверх заливки остаётся читаемым; на светлых темах (Мята, Лагуна) заливка не должна сливаться с фоном.
- На ночных темах — приглушённые, не кислотные цвета; дорожка не ярче 20–25 %.
- Цвета берутся из темы (её фон, свечение, кнопка), а не случайные.
- Три пресета одной темы — заметно разные идеи (например: «в тон фону», «контраст», «мягкий / пастель»).
- Исходный вид приложений не меняется: пресеты — только варианты для сравнения в студии.
