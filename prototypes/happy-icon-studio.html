Заменённые позиции видны в студии сразу, но пока не изменяют исходные PNG и приложение Sport. Для переноса между устройствами сохрани JSON.

Структура / персонажи

Профиль персонажа

Персонаж существует отдельно от изображений: один человек может показывать много видов спорта и упражнений. Изменение имени обновит все его позиции.
Редактирование изображения позиции

Заменить иконку

Заменится только изображение в выбранной позиции. Название и постоянный ID сохраняются; исходный PNG в GitHub не удаляется.
