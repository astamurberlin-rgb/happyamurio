## Проверки и сборка

Из корня репозитория:

```sh
node scripts/sync-shared-ui.mjs
node scripts/check-layout.mjs
node scripts/check-shared-ui.mjs
node meal-23/checks/check-startup.mjs
npm --prefix meal-23/sport run build
npm --prefix meal-23/sport run check
```

В `shared/apps.json` указаны собственные `sharedDirectory` и `accountScript`: сборщик использует профильный адаптер из проверенного HTML и форму аккаунта этой версии. Основной код синхронизации (`journal-sync.js`, `journal-model.js`, `local-store.js`) перенесён без изменения байтов.

Перед публикацией также пройдены исходные проверки журнала, IndexedDB, транспорта свыше 6 MB и самостоятельных библиотек; проверки времени питания, отчётов и прежней сборки Sport. Публикация не выполняет серверные миграции и не содержит личных записей. Повторный вход на физическом iPhone уже по адресу GitHub автоматически не выполнялся.
