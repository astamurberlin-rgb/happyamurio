# Happy Sport — основной вариант и слои

Утверждённый вариант: второй эскиз, после уменьшения светлого пятна за головой. Дата: 29 октября 2026.

## Файлы

- `happy-sport-main.png` — утверждённая визуализация, исходный PNG 1254 × 1254; сохранён без изменения байтов.
- `01-background.png` — непрозрачный градиент, 1024 × 1024, без фигуры и падающей тени.
- `02-denis-barbell.png` — Денис вместе со штангой, 1024 × 1024, с прозрачностью снаружи силуэта и в просветах, без тени под ногами.

Слои подготовлены из растровой визуализации. Основным визуальным эталоном остаётся `happy-sport-main.png`. Они не заменяют исходный авторский вектор. Внутри силуэта сохранён тёмный сливово-синий тон с небольшим изменением цвета.

## Сборка в Apple Icon Composer

1. Создать холст для iOS 1024 × 1024.
2. Использовать `01-background.png` как непрозрачный полноразмерный фон.
3. Добавить `02-denis-barbell.png` как один передний слой; совместить полные холсты, не центрировать по обрезанным границам фигуры.
4. Сравнить с утверждённым визуальным эталоном. Нужны высокая плотность силуэта, слабое преломление, короткая мягкая тень и очень сдержанный блик. Не добавлять яркий ореол за головой или сплошной светящийся кант.
5. Проверить маленький размер, Default, Dark и Mono/Clear. Маску скругления задаёт система.

Это исходные PNG, а не готовый или проверенный файл `.icon`. Системный материал и освещение нужно проверить в Icon Composer на Mac и на устройстве.

## Решение по стилю

Сохранить цельный силуэт Дениса со штангой и фирменный розово-фиолетово-синий градиент. Умеренный, почти плоский рельеф. Не возвращать выбеленное пятно за головой, толстую фаску или вид стеклянной игрушки.
