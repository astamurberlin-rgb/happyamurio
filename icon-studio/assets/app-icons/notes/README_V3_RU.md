# Notes (Файлы Happy) — значок, версия 2 · 7 ноября 2026

Плоская рукописная надпись notes: линия одной толщины, без теней. Надпись нарисована как трафарет: чёрная пластина с прорезанными буквами лежит поверх цветного градиента. Все слои на квадратном холсте 1024 × 1024, поэтому совпадают по положению.

Контур — перерисованный и сглаженный: края без дрожания, слово по центру (центр 511,5 × 507,5), петля у «o» сохранена.

## Градиент

Радиальный, центр в точке (551, 172) холста 1024, радиус 560:

- 0 % — `#D152B8` розовый
- 32 % — `#B153D6` сиреневый
- 60 % — `#6B5CE7` фиолетово-синий
- 82 % — `#286DE0` синий
- 100 % — `#14B8B4` бирюзовый

Фон и пластина — чистый чёрный `#000000`.

## Файлы

## Для Apple Icon Composer

1. Фон: `v3_01_background_gradient_1024.png` (или простой градиент самого Composer по цветам выше).
2. Передний слой: `v3_02_stencil_plate_1024.png` или SVG. Не скругляйте и не обрезайте слой: углы, стекло и параллакс добавляет система.
3. Толщина во внутренних гранях прорези и параллакс — это эффекты стекла Composer: настраиваются в самой программе (зеркальный блик, прозрачность, тень), в файлах их нет. Проверьте на макете и на устройстве: большая пластина получает эффекты целиком.
4. Сохраните нативный `.icon` в Composer на Mac.

Нативный `.icon` не собирался и не проверялся на Mac. Предыдущая версия (чёрная пластина, вертикальный градиент `#7642FF → #DC46BE → #FF6880 → #FF9646`) сохранена в библиотеке как история: файлы `01…06` и архив `Happy_Notes_Apple_Composer.zip`.
