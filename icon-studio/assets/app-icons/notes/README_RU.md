# Notes (Файлы Happy) — исходники значка

Значок страницы «Файлы»: чёрная пластина, в ней прорезана рукописная надпись notes, сквозь прорезь виден вертикальный градиент. Все слои на одном квадратном холсте 1024 × 1024, поэтому сохраняют расположение.

## Градиент

Сверху вниз, от верхушки буквы t до низа строчных букв:

- 0 % — `#7642FF` фиолетовый
- 34 % — `#DC46BE` пурпурный
- 68 % — `#FF6880` розовый
- 100 % — `#FF9646` оранжевый

Фон и пластина — `#060609`. Тень края прорези — `#140628`, непрозрачность до 55 %, сдвиг вниз-вправо.

## Для Apple Icon Composer

1. Создайте иконку с фоном `#060609`. Файл `01_background_black_1024.png` — образец фона.
2. Добавьте `02_notes_gradient_1024.png`: прозрачный слой цветной надписи с уже вписанной тенью края.
3. Настройте материал и проверьте режимы оформления. Системные эффекты Icon Composer могут изменить вид слоя: проверьте на макете и устройстве. Скругление углов добавляет система.
4. Сохраните нативный файл `.icon` в Icon Composer на Mac.

`02_notes_shape_1024.svg` — векторный одноцветный контур надписи. Его используют вместо, а не вместе с цветным PNG: можно залить его градиентом в самом Icon Composer по цветам выше.

## Вариант «трафарет»

Тот же значок можно собрать как настоящий трафарет: внизу `03_gradient_fill_1024.png` (градиент на весь квадрат), сверху `04_stencil_plate_1024.png` (пластина с прорезанной надписью и тенью края). Результат совпадает с основным вариантом. В Icon Composer надёжнее основной вариант: большая пластина на переднем плане получит системные эффекты стекла.

`05_notes_flat_1024.png` — готовая плоская иконка. `06_web_icon_*` — уменьшенные значки для сайта, 180 × 180 для экрана iPhone.

Нативный `.icon` не собирался и требует проверки в Apple Icon Composer.
