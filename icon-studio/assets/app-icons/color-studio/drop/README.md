Оригинал — утверждённая версия с каплей. Градиент — отдельно восстановленное изображение, скрытые области приблизительны. PNG-слои 1024×1024 восстановлены из оригинала; SVG-маска содержит растровую маску, а не векторные контуры. Для Apple Icon Composer используйте прозрачные PNG-слои; SVG с маской может не поддерживаться. Нативный .icon на Mac не собран.
