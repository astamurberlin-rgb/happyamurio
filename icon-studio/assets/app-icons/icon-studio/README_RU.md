# Happy Icon Studio — исходники значка

Иконка собрана по присланному квадрату: чёрный фон, надпись «icon» с розово-фиолетово-синим градиентом и белая надпись «STUDIO». Все основные слои имеют одинаковый квадратный холст 1024 × 1024, чтобы сохранить их расположение.

## Для Apple Icon Composer

1. Создайте иконку с чёрным фоном `#000000` в Icon Composer. Файл `01_background_black_1024.png` оставлен как отдельный образец фона.
2. Добавьте `02_icon_gradient_1024.png`: это прозрачный слой цветной надписи «icon».
3. Выше добавьте `03_studio_white_1024.svg` или `03_studio_white_1024.png`: это одна и та же белая надпись «STUDIO» на прозрачном фоне. Выберите один из двух форматов.
4. При необходимости откорректируйте цвета, прозрачность и материал. Системные эффекты Icon Composer могут изменить внешний вид слоёв: проверьте на макете и устройстве. Скругление добавляет система, заранее обрезать углы не нужно.
5. Сохраните нативный файл `.icon` в Icon Composer на Mac и проверьте нужные режимы оформления.

`02_icon_shape_1024.svg` — альтернативный векторный одноцветный контур рукописной надписи для перекрашивания; его используют вместо, а не вместе с цветным слоем `02_icon_gradient_1024.png`. Градиент сохранён именно в PNG, чтобы перенести его внешний вид.

`04_combined_foreground_1024.png` объединяет обе надписи на прозрачном фоне и удобен в редакторе студии; не добавляйте его поверх двух отдельных надписей. `05_happy_icon_studio_flat_1024.png` — готовая плоская иконка на чёрном фоне. Файлы `06_web_icon_*` — уменьшенные значки для сайта, включая 180 × 180 для экрана iPhone.

Исходники подготовлены для импорта. Нативный `.icon` и его системные эффекты не собирались и требуют проверки в Apple Icon Composer.
