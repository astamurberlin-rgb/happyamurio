# Иконки Happy Sport

Каталог `catalog.json` содержит 93 PNG: 45 основных значков занятий и оборудования
в `base/` и 48 дополнительных вариантов в `people/`. Все файлы имеют прозрачный фон.
Номера и `id` сохранены: существующий выбор пользователя в тренировке продолжает работать.

Основные картинки постепенно заменены на персонажей Happy Sport, созданных для
соответствующих занятий. Иконки показываются целиком внутри квадратной области без
растягивания. Дополнительные варианты персонажей остаются доступны в выборе иконки.

Добавлены отдельные изображения для стрельбы из лука, верховой езды, биатлона,
жима ногами, рыбалки, парусного спорта, фигурного катания и беговой дорожки.
Старое значение `sport:30_skates_rollers` теперь показывает ролики; для фигурного
катания есть свой новый значок.

Новые иконки можно выбрать в настройках тренировки. При узнаваемом названии
приложение также может подобрать соответствующую картинку автоматически; явно
выбранная пользователем иконка имеет приоритет. Жим ногами использует изображение
Римы, остальные силовые тренажёры сохраняют общий значок.

Не редактировать копию `sport/sport-icons/` напрямую: сборка копирует каталог
и изображения из `sport/src/sport-icons/`.
