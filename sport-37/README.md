Из этой папки:

```sh
node scripts/build-release.mjs
npm --prefix sport run check
node scripts/verify-release.mjs
```

Сборщик обновляет только файлы внутри этого выпуска. Контрольные суммы всех включённых файлов и происхождение исходников — в `SOURCE-PROVENANCE.json`. Все тренировочные данные в автоматических проверках искусственные; личные выгрузки не входят в код или публикацию.

На новом домене нужно войти тем же существующим аккаунтом Happy. Облачный документ sport/journal прежний; пользовательские данные публикация кода не меняет. Локальное хранилище Sites не переносится в GitHub, а серверная копия загружается после входа.

Ключи аккаунта, профильного журнала и резерва сохранены из согласованной версии. Резерв читает v3 и компактный v4, экспорт остаётся обычным JSON v3. Независимые изменения объединяются по ID, реальные конфликты сохраняют обе копии. Статус и диагностика находятся в настройках под профилем; в шапке статуса нет.

Ограничения исходной сборки сохранены: регистрация, отдельный обмен сводками, общими замерами и счётчиками с Day/Meal и Icon Studio здесь не включены. Навигационные информационные страницы закреплены за выпуском. Серверная схема и разрешения не менялись.
