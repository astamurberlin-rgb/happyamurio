# Зависимости Happy Day Update 52

Этот набор закреплён за `day-52/index.html`. Он перенесён из опубликованной сборки Sites v2. `profile-storage.js` извлечён из исполняемого блока исходного HTML, чтобы сохранить защиту смены аккаунта и отделение гостевого дневника. Общие зависимости остальных приложений находятся в корневой папке `shared/`.

`shared/apps.json` в корне задаёт `day.sharedDirectory`, который используют сборщик встроенных компонентов и проверки. Переходить на другие общие версии можно только вместе с проверками аккаунтов, профилей и синхронизации Day.
