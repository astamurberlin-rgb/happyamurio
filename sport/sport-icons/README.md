# Happy Sport — полный набор PNG

В этой папке собраны 37 базовых файлов и 48 вариантов персонажей в двух размерах: 512 × 512 и 1024 × 1024 пикселя. Всего 170 отдельных PNG-файлов с прозрачным фоном, RGBA, 8 бит на канал.

## Папки

- `PNG_512x512/Base/`: 37 базовых файлов.
- `PNG_512x512/People/`: 48 вариантов персонажей.
- `PNG_1024x1024/Base/`: 37 базовых файлов в большем размере.
- `PNG_1024x1024/People/`: 48 вариантов персонажей в большем размере.
- `Previews/`: обзорные листы для просмотра, не для вырезки иконок.
- `file-check.csv`: проверка размеров и прозрачности всех 170 PNG.

## Имена персонажных вариантов

- `_m_light`: мужчина, светлый оттенок кожи.
- `_f_light`: женщина, светлый оттенок кожи.
- `_m_dark`: мужчина, тёмный оттенок кожи.
- `_f_dark`: женщина, тёмный оттенок кожи.

Для каждой из 12 активностей есть четыре варианта: отжимания, бег, ходьба, плавание, растяжка, йога / пилатес, аэробика / HIIT, разминка со скакалкой, скалолазание, сёрфинг, танцы, адаптивный спорт. Походы не входят в исходную серию из 48 персонажных вариантов.

Вариант, уже представленный базовой иконкой, использует тот же рисунок без повторной перерисовки. Остальные варианты созданы по базовым рисункам с сохранением вида спорта, одежды, оборудования и общего характера позы; небольшие различия деталей возможны.

## Учтённые правки

- Литая оранжевая гантель.
- Белая боковая полоска на синих брюках бегуна.
- Спортивные брюки с полоской и кепка для ходьбы.
- Скакалка для разминки.
- Волан с округлым наконечником.
- Лыжи и сноуборд отдельными файлами.
- Кроссовки для «Другой активности» вместо звезды.

Файлы `36_sneakers.png` и `37_other_activity.png` намеренно содержат одинаковые кроссовки для двух позиций реестра. Поэтому 37 базовым файлам соответствуют 36 разных базовых рисунков.

Иконки не содержат подписей или фоновых плашек. Светлый фон на обзорных листах служит только для удобства просмотра: отдельные PNG в папках Base и People прозрачные.

PNG — растровые, не векторные файлы. Рабочая область вписана в квадратный холст с прозрачными полями для интерфейсных контейнеров.
