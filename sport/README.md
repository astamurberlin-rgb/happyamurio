# Happy Sport

Актуальные исходники Sport находятся здесь, в общем репозитории Happy.
Начальная версия переноса — v34, включая выбранный компактный дизайн
подходов, разделители ×, таймеры, перерывы и 85 иконок.

## Сборка и проверка

Требуется Node.js 18 или новее; внешних npm-зависимостей нет.

```sh
cd sport
npm run build
npm run check
```

`src/` и `data/` — исходники. Не редактировать `index.html` вручную:
он генерируется сборкой. Сборка обновляет страницу и ресурсы в этой папке
для GitHub Pages, а также создаёт игнорируемый `dist/`.
В коммит должны попадать и исходники, и обновлённые `index.html`,
`sport-icons/`, `exercises/`.
В публичном `data/seed.json` остаются только справочники: массивы истории
тренировок, замеров и исходных замеров пустые. Сборка проверяет это условие.
Существующее локальное состояние браузера сборка не удаляет.

## Пути

Основной адрес: <https://astamurberlin-rgb.github.io/happyamurio/sport/>.
Иконки загружаются из `sport-icons/`, техника подтягиваний — из
`exercises/pull-up.html`. Все пути относительные, учитывают `/happyamurio/`.
Ссылки на упражнения `?exercise=<id>` и тренировки `?workout=<id>`
сохраняют путь текущей страницы.

Ссылки на соседние приложения: `../meal/` и `../day/`. В Sport нет собственных копий Meal и Day.
`scripts/check-paths.mjs` проверяет пути всех трёх страниц, каталог иконок
и соответствие публикуемого HTML результату сборки.

Проверка в браузере из корня репозитория:

```sh
python3 -m http.server 4174
```

Открыть `/sport/`, затем настройки и переходы в Meal/Day. Запуск только
`sport/dist/` не подходит для проверки переходов между приложениями:
соседние приложения расположены в `meal/` и `day/` общего репозитория.

Состояние обмена данными и правила параллельной работы:
[карта приложений](../APPS.md).

## Перенос полного журнала
В настройках доступны «Выгрузить JSON», «Загрузить JSON», «Сохранить журнал в облако» и «Восстановить из облака». Полная копия сохраняется вручную как зашифрованная запись sport/journal в Supabase app_sync; перед восстановлением есть предпросмотр и локальная копия для отмены. Токены и ключи аккаунта не экспортируются. Поддерживается прежний JSON Sport v1. JSON Meal и Day восстанавливается в соответствующем приложении. Автоматический обмен sport/link по-прежнему содержит только сводку; он не означает полную синхронизацию журнала. Для чтения зашифрованной копии нужен тот же пароль: сброс пароля старый ключ не восстанавливает. Реальный вход и перенос между устройствами пользователя пока не проверены.
