## 2.1 · действия с документом

«Копировать», 🔗 и «⋯» расположены вместе в шапке открытого документа. Меню убрано с карточек выбора. Окна закрываются верхней полоской: тап или свайп вниз. «Отменить» закрывает редактор без записи в общую базу; набранный текст остаётся восстановимым черновиком на устройстве. На время сохранения закрытие блокируется.

## Хранение и сохранение

См. `../DATA-STORAGE.md`, раздел Happy Notes 2.0. Исходник серверного канала — `../supabase/functions/notes-write/`. Чтение сохраняет прежний API. Новые заметки создаются только через явное сохранение после импорта; существующие — через версионную функцию с историей. Кнопка 🔗 над текстом копирует прежнюю прямую ссылку для ИИ с ключом доступа; пункт «Поделиться ссылкой» в меню даёт ссылку на страницу без ключа. Значение ключа берётся только из браузера при нажатии.
