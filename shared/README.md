# Общие компоненты Happy

`apps.json` фиксирует постоянные входы и текущие версии.
Вход и синхронизация пока остаются внутри приложений (Sport: `sport/src/happy-auth.js`
и `sport/src/sport-cloud.js`; Day/Meal: код в их `index.html`).
Перенос общего runtime сюда делать отдельно, после согласования контрактов и тестов.
Здесь не хранить личные данные, сеансы и ключи. См. [карту](../APPS.md) и [хранение](../DATA-STORAGE.md).
