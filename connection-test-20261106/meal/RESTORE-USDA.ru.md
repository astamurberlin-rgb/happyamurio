# Восстановление USDA в Happy Meal 22.11-usda-test.13

В тестовой ветке два одинаковых справочника USDA SR Legacy хранятся в gzip. После скачивания ветки распакуйте их перед запуском или сборкой Meal. Приложение и готовая сборка читают обычные JSON по своим исходным путям.

Из корня скачанного репозитория выполните команду в Python 3.

```sh
python3 connection-test-20261106/meal/restore-usda.py
```

Скрипт работает локально, проверяет оба архива и выводит `OK` для каждого восстановленного файла. Команду можно запускать повторно. Если какой-либо JSON уже существует и отличается от оригинала, скрипт остановится до записи. Сохраните такой файл отдельно и запустите команду снова.
