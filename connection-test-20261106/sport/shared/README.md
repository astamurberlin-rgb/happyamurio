# Общий интерфейс Happy

Образец общих элементов — Happy Meal. `happy-ui.css` задаёт поля, карточки, кнопки,
отступы и нижнюю строку версии; `happy-ui.js` рисует одну форму аккаунта и управляет
показом пароля, вводом с клавиатуры, состояниями ожидания и ошибок.

Серверные вызовы и хранение дневников остаются в приложениях и подключаются через адаптер.
Здесь не хранить личные записи, токены и ключи.

## Правила

- Общие настройки идут первыми: «Аккаунт», «Резервная копия», «Связанные приложения».
- Поля почты и пароля занимают ширину карточки. Показ пароля — внутри поля.
- «Войти» слева, «Создать аккаунт» справа в одной группе; перенос на новую строку допускается на узком экране.
- Кнопки высотой от 44 px, радиус 14 px, отступ между ними 8 px. Основная кнопка светлая, вторичная прозрачная.
- Одинаковые действия называются одинаково: «Выгрузить дневник», «Загрузить из файла», «Обновить связь», «Выйти».
- Дополнительные возможности приложения размещаются после общих; облачный резерв показывается только там, где он реализован.
- Настройки всегда последняя вкладка с шестерёнкой. Название, версия и дата — последний элемент настроек.
- Палитры приложений сохраняются; общие элементы используют одинаковую геометрию и типографику.

## Сборка

```sh
node scripts/sync-shared-ui.mjs
npm --prefix sport run build
node scripts/check-shared-ui.mjs
npm --prefix sport run check
node scripts/check-layout.mjs
```

Day и Meal получают общий код внутрь HTML при синхронизации, Sport — при сборке.
Готовые страницы работают без отдельной загрузки общего скрипта или таблицы стилей.
Не править встроенные блоки `HAPPY_SHARED_STYLE` и `happy-shared-ui` вручную.
Для отдельной сборки Sport через Sites копировать общий код в его `shared/` и сохранять
те же исходники UI. Номера приложений находятся в `apps.json`.

## Общий профиль · 30.10.2026

Вход содержит почту и пароль. «Создать аккаунт» открывает отдельную форму с необязательным именем. После входа «Изменить имя» сохраняет только Auth user_metadata.display_name через авторизованный PUT /auth/v1/user. GET того же пользователя обновляет имя при открытии/возврате и обновлении связи. Имя — отображение, никогда не идентификатор владельца или право доступа. Пароли и шифрование не меняются.
