### Как читает Happy Meal Update 25

- Энергия, белки, жиры → поля Meal; углеводы этикеток ЕС/Великобритании/России и других регионов → поле «Углеводы» с пометкой «как указано на этикетке»; углеводы этикеток **США** («Total Carbohydrate», включая клетчатку) и USDA 1005 — отдельной строкой, в общей строке «нет данных», как у справочника USDA.
- Насыщенные ЖК, сахара, соль, клетчатка, натрий, холестерин, витамин D, кальций, железо, калий → поля Meal при совпадении единиц; остальное (кДж, трансжиры, добавленные сахара) — свои свойства карточки `prop:dessert:*`. USDA-ключи моделей — по таблице соответствий справочника USDA (`prop:usda:<id>` для несопоставимых).
- «Менее N» хранится как граница (`sourceQualifier.state = less_than`) и показывается «< N г»; в итогах — как граница.
- Порции — только из данных источника: «шт» для одного изделия, «порция ≈ N шт» для упаковочной порции, «шт» по рецепту автора; восемь карточек без размера порции записываются по введённым граммам. Миллилитры в граммы не переводятся.
- Сохранённые записи дневника не пересчитываются при обновлении библиотеки (снимки состава).
