# Библиотека иконок Happy Sport · v1

Общая папка картинок занятий и оборудования для выпусков Happy Sport. Публикуется по постоянному адресу

```
https://astamurberlin-rgb.github.io/happyamurio/assets/sport-icons/v1/
```

и подключается сборкой выпуска: `catalog.json` встраивается в `index.html`, а пути картинок получают этот
префикс. Так иконки хранятся один раз, а не в каждом каталоге выпуска (в Update 37 они занимали 34 МБ на копию,
и копий было шесть).

## Содержимое

- `catalog.json` — 93 записи: `id` (`sport:01_barbell`…), `src` относительно этой папки, подпись, группа, номер,
  псевдонимы для автоподбора и персонаж. `id` и номера совпадают с прежним каталогом Sport 36.3–38: сохранённый
  выбор иконки в тренировках продолжает работать.
- `base/` — 45 основных значков, `people/` — 48 вариантов персонажей. PNG 512×512 с прозрачным фоном.
  В приложении картинка показывается не крупнее 64 CSS px (192 px на экране 3×), поэтому 512 px достаточно.

## Правила

- **Папка неизменяемая.** Файлы внутри `v1/` не редактируются и не удаляются: на них ссылаются опубликованные
  выпуски. Новый или изменённый набор иконок — новая папка `v2/` рядом; новый выпуск Sport переключается на неё
  в `sport/scripts/build.mjs` (`SPORT_ICON_LIBRARY`), прежние выпуски остаются на своей версии.
- Мастера в полном размере (1254×1254) здесь не хранятся: они лежат в Icon Studio (`icon-studio/sport-icons/base/`,
  байт в байт те же файлы) и в `sport-37/sport/src/sport-icons/`. Веб-версия получена уменьшением с
  премультиплицированной альфой (без тёмной каймы) и сжатием PNG без потерь.
- Личных данных здесь нет; это публичный справочник, как `meal-data/`.
