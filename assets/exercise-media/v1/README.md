# Картинки упражнений Happy Sport · v1

Общая папка картинок упражнений: заглавная картинка (обложка) и кадры фаз движения. У каждого упражнения — своя
подпапка с именем его `id` из библиотеки упражнений (`assets/exercise-library/v1/`). Вариант хвата — это отдельное
упражнение со своим `id`, поэтому у каждого варианта свои картинки.

Постоянный адрес после выпуска: `https://astamurberlin-rgb.github.io/happyamurio/assets/exercise-media/v1/`

## Что положить

```
assets/exercise-media/v1/<id упражнения>/cover.png     заглавная картинка
assets/exercise-media/v1/<id упражнения>/start.jpg     кадр «Старт»
assets/exercise-media/v1/<id упражнения>/mid.jpg       кадр середины движения («Подъём» и «Вниз»)
assets/exercise-media/v1/<id упражнения>/top.jpg       кадр «Верх»
```

- **cover** — PNG или WebP, 512×512, прозрачный фон, персонаж целиком в кадре. Тот же формат, что у иконок
  `assets/sport-icons/v1/` (в приложении показывается не крупнее 64 px, в списке библиотеки и в тренировке).
- **start / mid / top** — JPG, PNG или WebP, вертикальный кадр 3:4 (например 900×1200), тёмный фон как в карточке
  упражнения, фигура по центру, перекладина у верхнего края. Три кадра одного варианта — в одном масштабе и с одной
  точки, иначе при перетаскивании ползунка фигура «прыгает».
- Имена файлов — строго как выше, строчными буквами. Другие имена сборка не примет.

## Семейство «Подтягивания»: пять папок и отдельная карточка

| Папка (`id`) | Пилюля | Что должно отличать картинку |
|---|---|---|
| `pull-up` | Прямой | ладони от себя, руки на ширине плеч |
| `wide-pull-up` | Прямой широкий | ладони от себя, руки шире плеч |
| `pull-up-narrow` | Прямой узкий | ладони от себя, руки уже плеч |
| `chin-up` | Обратный | ладони к себе, руки на ширине плеч |
| `chin-up-narrow` | Обратный узкий | ладони к себе, руки уже плеч |
| `neutral-pull-up` | — (своя карточка) | ладони друг к другу, две параллельные рукояти |

## Заглушка библиотеки

`placeholder.png` — Дэниел сидит на полу с полотенцем, водой и гантелью (512×512, прозрачный фон). Поле `placeholder`
в `catalog.json` называет файл. Заглушка показывается только вместо запасного значка «Другое занятие» (кроссовки) —
у упражнений, для которых приложение не нашло картинку по названию и категории, и у своих упражнений. Картинки,
найденные по названию или категории, остаются. `exercise-media.mjs` переносит поле `placeholder` как есть.

## Как это попадает в приложение

1. Положить файлы в папку упражнения.
2. `node sport-NN/sport/scripts/exercise-media.mjs` — пересобирает `catalog.json` по содержимому папок и печатает,
   каких картинок ещё нет.
3. Собрать выпуск. Обложка заменит общую иконку вида спорта в библиотеке и в тренировке; кадры заменят общие кадры
   семейства в карточке упражнения. Нет картинки — показывается прежняя общая, ничего не ломается. Если у варианта
   есть все три своих кадра, подпись «Кадры пока общие для вариантов хвата» исчезает.

Картинка, назначенная вручную в Icon Studio, по-прежнему важнее обложки из этой папки.

## Правила

- Папка только растёт. Заменить картинку — положить новую версию и записать замену в CHANGELOG выпуска; опубликованные
  выпуски ссылаются на эти адреса.
- Личных данных здесь нет.
