# Библиотека упражнений Happy Sport · v1

Общий справочник упражнений, оборудования и групп мышц для выпусков Happy Sport. Отделён от оболочки приложения:
выпуск встраивает библиотеку при сборке (`sport/scripts/build.mjs`, константа `EXERCISE_LIBRARY`), поэтому
опубликованная страница самодостаточна и работает офлайн, а источник у всех выпусков один.

Постоянный адрес: `https://astamurberlin-rgb.github.io/happyamurio/assets/exercise-library/v1/`

## Файлы

- `exercises.json` — 137 упражнений: `id` (устойчивый, например `cable-triceps-pushdown`), `name`, `en`, `aliases`
  (синонимы для поиска и автоподбора), `category`, `equipment` (ссылки на `equipment.json`), `profile`
  (`load_reps`, `reps`, `hold`, `band_reps`, `distance_time`, `timed_reps`), `loadBasis` (как учитывать нагрузку:
  `machine_display` — шкала тренажёра, `per_hand` — на одну руку, `total_external` — общий внешний вес,
  `single_implement` — один снаряд, `plates_only` — только диски), `scope`, и с v1 — `handles`: варианты рукояти
  для упражнений на блоке (канат, прямая, V-рукоять…). Рукоять — пометка на упражнении в конкретной тренировке;
  подходы и нагрузка при этом не пересчитываются и не объявляются равноценными.
- `equipment.json` — 23 вида оборудования.
- `exercise-muscles.json` — группы мышц по `id` упражнения.
- `manifest.json` — версия схемы и библиотеки, дата, счётчики, размер и SHA-256 каждого файла.

## Правила

- `id` устойчивы: не удаляются и не переименовываются; история тренировок хранит `id` и не пересчитывается при
  обновлении справочника. Папка только растёт: новые упражнения, поля и синонимы добавляются сюда с обновлением
  `manifest.json` (версия, хеши). Несовместимое изменение схемы — новая папка `v2/`.
- Выпуск записывает в своём `SOURCE-PROVENANCE.json`, из какой версии библиотеки он собран. Старые выпуски не
  меняются: у них библиотека уже внутри `index.html`.
- Личных данных здесь нет: это публичный справочник, как `meal-data/`.
